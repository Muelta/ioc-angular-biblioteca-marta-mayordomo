# IocAngularBibliotecaMartaMayordomo

La Meva Biblioteca

- Autora: Marta Mayordomo Robledo

- Descripció:
    La Meva Biblioteca és una aplicació web desenvolupada amb Angular que permet organitzar i consultar informació sobre llibres d'interès personal.
    L'aplicació mostra una col·lecció de llibres, lectures pendents, valoracions i informació bàsica de la biblioteca.

- Versions utilitzades:
    - Node.js v24.21.0
    - npm 11.19.0
    - Angular CLI 22.2.0
    - Git

- Instal·lació i execució:
    - Instal·lar les dependències: npm install
    - Iniciar el servidor: ng serve -o
    - Obrir el navegador a: http://localhost:4200/
    - Executar els tests: ng test
    - Compilar el projecte: ng build

- Branca de treball: ra2-components

- Components creats: 
    - LlistaElementsComponent: mostra la llista de llibres.
    - TargetaLlibreComponent: mostra les dades de cada llibre.
    - CategoriaLlibreComponent: mostra les categories.
    - FiltreLlibresComponent: permet cercar i filtrar llibres.

- Funcionalitats implementades
    - Model Book i dades mock de 10 llibres.
    - Comunicació entre components amb @Input i @Output.
    - Cerca i filtres per text i categoria.
    - Formulari amb FormsModule, ngModel i validacions.
    - Comptador de resultats i missatge sense resultats.
    - Detall del llibre seleccionat.
    - Format de dates amb DatePipe.
    - Accessibilitat i disseny responsive.  

- Enllaç del repositori: https://github.com/Muelta/ioc-angular-biblioteca-marta-mayordomo.git
